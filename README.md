
This web consist of Online Appointment System, a modern platform that allows patients to book, manage, and track medical appointments online.
This system was developed to make healthcare scheduling simple, efficient, and accessible for both patients and clinic staff.
Patients can easily view available doctors, book appointments, and receive notifications.
Doctors and administrators can manage schedules, patient records, and appointments from a centralized dashboard.

 Features
* Create an account and log in securely
* Browse doctors by specialization
* Book, cancel, or reschedule appointments
* Receive notification of confirmations

 Technology Stack
 * HTML
 * CSS
 * JavaScript
